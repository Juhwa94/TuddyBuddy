# AI 기반 학습 지원 서비스 TuddyBuddy
> TuddyBuddy는 내 학습 자료로 복습하고, 부족한 부분을 분석하며, 함께 공부할 환경을 하나의 서비스에 모으는 웹 프로젝트입니다. 자료로 문제를 만들고, 결과를 분석하고, 스터디룸에서 함께 학습하는 서비스입니다. 

## 👨‍🏫 프로젝트 소개
> 본 프로젝트는 학습의 단계를 연결하여 자신의 교재와 노트로 문제를 만들고, 풀이와 오답을 학습기록으로 남기는데 있습니다. 이 기록을 분석해 다음 학습에 참고하고, 스터디룸에서는 자료와 일정, 대화를 함께 관리합니다. 집중학습과 다이어그램, 버디봇은 이 흐름을 이어가는 보조 기능 입니다. 핵심 기능은 AI 개인 스터디와 그룹 스터디, 학습 통계, 출석과 친구추가, 커뮤니티, 버디봇 등의 기능을 제공합니다. 관리자는 회원과 콘텐츠, 신고와 이용 이력을 관리합니다.

## 📌 주요 기능

> - AI 개인 스터디 : 사용자 학습 자료를 실제 문제 풀이와 복습을 연결하는 핵심 기능입니다. Python FastAPI는 Gemini와 Groq를 활용해 문제 생성과 검증을 수행합니다. 최종 결과는 Oracle에 저장합니다. Spring Boot는 요청을 받아 학습 세션을 관리하고, 문제 생성에 필요한 AI 호출과 답안 결과 저장을 연결합니다. 화면의 순서대로 이미지와 분류 입력, 문제 생성과 세션에 저장, 답안 채점과 결과 저장, 오답과 학습 기록 재조회가 이어집니다. 그리하여 화면 상태와 서버에 남는 학습 데이터를 나누어 관리해, 사용자가 풀이를 마친 뒤에도 같은 학습 내용을 다시 확인할 수 있도록 했습니다.
> - 학습평가분석 : 평가분석은 누적된 학습 결과를 다음 공부의 참고 자료로 바꾸는 기능입니다. 사용자가 분석을 요청하면 프론트는 인증 정보와 필요한 요청값을 서버에 전달합니다. 컨트롤러는 요청을 서비스로 넘기고, 서비스는 포인트 차감과 성적 이력 조회를 진행합니다. 분석에 필요한 데이터를 AI 서버에 전달하고 결과를 받으면, 분석 내용과 차트 데이터를 하나의 응답으로 묶어 반환합니다. 프론트는 이 응답으로 분석 결과를 표시합니다.
> - 스터디룸 : 스터디룸은 함께 공부할 대상을 찾고 협업하는 공간입니다. 태그로 원하는 스터디룸을 검색하고, 공개, 비공개 설정으로 참여 방식을 구분합니다. 비공개 방은 초대코드로 참여합니다. 참여한 멤버는 이후 소개할 일정과 할 일, 자료와 대화를 같은 공간에서 관리합니다. 기능별 메뉴를 분리하면서도 하나의 스터디룸에 연결해 공동 학습의 흐름을 만들었습니다. 서브 기능으로는 해야할일, 다이어그램, 일정, 참고자료, 질의응답, 메모 등의 기능들이 있습니다.
> - 출석 기능 : 출석시 포인트 지급의 기능도 제공합니다. 출석 요청은 로그인 처리 상태를 확인하고 잠금으로 중복 클릭을 막습니다. 출석 회원은 요청값이 아닌 서버의 로그인 인증 정보로 결정합니다. 그 외에 React로 구현한 달력에 월별 출석 기록과 서버 기준 오늘을 표시합니다. 서버의 지급 성공 응답을 확인한 뒤 300P 보상 팝업을 보여줍니다.
> - 친구 기능 : 친구를 추천해주고 친구 요청을 수락하면 관계상태를 변경하고 대기 목록에서도 제거합니다. 사용자는 회원 코드를 입력해 검색하거나, 회원 프로필에서 친구 요청을 보낼 수 있습니다.
> - 커뮤니티 : 커뮤니티는 이용자들이 공통의 관심사를 바탕으로 정보를 공유하고 댓글과 좋아요를 누르며 자유롭게 소통할 수 있는 공간입니다. 게시글을 쓰며 공통의 관심사를 공유하고 닉네임으로 글 작성 후 작성일자와 조회수 및 좋아요 수를 확인할 수 있습니다. 읽기 전용 트랜잭션을 통한 특정 회원이 작성한 글의 총 개수와 페이징된 목록을 조회하는 검색 기능도 추가했습니다. 게시글은 카테고리 버튼을 동적으로 만들어 선택한 탭 상태로 반영하였습니다. 또한 좋아요 버튼을 누르면 로그인 상태와 중복 요청 여부, 게시글 번호가 유효한지 확인합니다.
> - 알림 기능 : 알림은 사용자 활동으로 생성된 내용을 DB에 저장하고, SSE로 수신자에게 전달합니다. 프론트는 수신한 이벤트로 화면을 갱신해 새로고침 없이 알림을 확인할 수 있습니다. 서버에서 브라우저로 전달하는 흐름이 중심이므로 SSE를 선택하였고, 저장된 이력과 실시간 표시를 함께 제공하는 구조입니다. JWT로 SSE에 연결하고, 알림 확인 시 DB에 읽음 상태를 반영합니다.
> - 마이페이지 : 마이페이지는 회원정보, 친구 코드를 확인하고, 정보 수정 화면에서 닉네임과 전화번호를 관리합니다.
> - 관리자페이지 : 관리자는 회원 권한과 탈퇴를 처리하고 부적절한 게시글을 정리합니다. 스터디 삭제와 참여자 알림, 학습 콘텐츠의 비활성화 및 복구, 삭제를 관리합니다. 그리고 조건별 검색과 페이지 이동으로 사용자 활동 이력을 확인합니다.



## 📂 프로젝트 특징
> 1. AI 기반의 맞춤형 자기주도 학습 환경 : AI 개인스터디 기능을 통해 학습자의 수준과 성향에 맞춘 최적화된 학습 콘텐츠를 제공하며, 효율적인 개인별 맞춤 학습을 지원합니다.
> 2. 정밀한 학습 진단 및 피드백 체계 : 학습평가분석을 통해 학습 성취도와 취약점을 객관적으로 진단하고, 이에 기반한 피드백을 제공하여 지속적인 실력 향상을 유도합니다.
> 3. 온라인 가상 공부방을 통한 집중력 향상 : 스터디룸 공부방 기능을 제공하여 물리적 제약 없이 다른 학습자들과 함께 공부하는 분위기를 조성하고 학습 몰입도를 높입니다.
> 4. 지속적인 학습 습관 형성을 위한 출석 관리 : 출석 기능을 통해 매일의 학습 참여를 기록하고 관리함으로써, 학습자가 꾸준한 학습 루틴과 성실성을 유지할 수 있도록 돕습니다.
> 5. 소셜 기능을 통한 상호작용 및 동기 부여 : 친구추가 기능과 커뮤니티를 통해 학습자 간 정보 공유, 소통, 선의의 경쟁을 유도하여 혼자 하는 공부의 지루함을 줄이고 학습 동기를 강화합니다.
> 6. 체계적인 사용자 및 플랫폼 운영 관리 : 마이페이지로 개인별 학습 이력과 활동 내역을 직관적으로 관리할 수 있으며, 관리자페이지를 통해 전체 서비스 운영과 사용자 관리를 효율적으로 수행할 수 있습니다.
